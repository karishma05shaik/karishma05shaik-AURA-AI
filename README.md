# AURA AI - AI Resume Analyzer

An AI-powered resume analyzer app built with React, TypeScript, Vite, and Supabase.

## Features

- **Phone OTP Authentication** - Login via WhatsApp OTP verification
- **Create ATS Resume** - Build professional resumes with multiple templates, download as PDF, export, edit, and share
- **Analyze Resume** - Upload a PDF resume and get an AI-powered score out of 10 against any job role, with strengths, weaknesses, missing elements, recommendations, and keyword analysis
- **Interview Questions** - Get frequently asked interview questions with sample answers for any job role
- **Settings** - Change phone number, change name, logout, or delete account

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Edge Functions)
- **Libraries**: jsPDF, html2canvas, pdfjs-dist, lucide-react

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
